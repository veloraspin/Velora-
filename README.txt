VELORA — NETLIFY STATIC DEPLOY

This is a standalone static reconstruction of the VELORA free-play arcade based on the available arcade.tsx source and screenshots. It is NOT an exact export of the complete live Replit project. Exact original game artwork and the underlying game library were not available. Six cover images and game symbols have been recreated.

Netlify deploy:
1. Unzip this archive.
2. Open Netlify > Add new project > Deploy manually (or https://app.netlify.com/drop).
3. Drag the extracted folder named velora-netlify (NOT the ZIP) onto the deploy area.
4. Netlify will publish index.html immediately; no build step or node modules needed.

Features: responsive dark/cyan/gold layout, six clickable free-play symbol games, game matching, filters, search, favourites, menu, info popups and session statistics.

Important: Free play only. No accounts, payments, deposits, withdrawals, prizes or connected live support. For an exact migration, export the complete Replit project, including all of its assets and source files.
